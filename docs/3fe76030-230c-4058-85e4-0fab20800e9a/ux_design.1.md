## 3. Указание точного количества

![Точное количество](/Users/user/.gemini/antigravity/brain/3fe76030-230c-4058-85e4-0fab20800e9a/claim_row_expanded_1769912319167.png)

**Когда участник хочет указать НЕ поровну:**
1. Нажимает на свой бейдж (долго или через меню)
2. Появляется степпер: `[ - ] 15 шт [ + ] = 1500₽`
3. Остаток делится между остальными отмеченными

**Логика расчёта:**
```
fixed_claims = участники с точным количеством
shared_participants = участники с "Ост." (остаток)
remaining = total_qty - Σ(fixed_claims)
per_shared = remaining / count(shared_participants)
```

## Прогресс-бар

```
┌──────────────────────────────────────────┐
│ ██████████████ ▓▓▓▓▓▓▓▓▓▓ ░░░░░░░░░░░░░ │
│   Я: 35%        Аня: 30%    Не распр: 35%│
└──────────────────────────────────────────┘
```

- Цветные сегменты = доли участников
- Серый = нераспределённый остаток
- Появляется под каждой строкой И в футере таблицы

## User Flow

```mermaid
flowchart TD
    A[Клик на строку] --> B{Есть claims?}
    B -->|Нет| C[Все участники = разделить поровну]
    B -->|Да| D[Показать текущие claims]
    
    C --> E[Шторка с бейджами]
    D --> E
    
    E --> F{Действие пользователя}
    F -->|Выбрать участника| G[Добавить в split]
    F -->|Убрать участника| H[Убрать из split]
    F -->|Указать точное кол-во| I[Открыть степпер]
    I --> J[Остаток делится между остальными]
    
    G --> K[Обновить прогресс-бар]
    H --> K
    J --> K
    
    K --> L[Готово]
    L --> M[Сохранить claims]
```
