## 1. Таблица чека (упрощённая)

![Таблица splitting](/Users/user/.gemini/antigravity/brain/3fe76030-230c-4058-85e4-0fab20800e9a/table_simplified_1769913185860.png)

**Принципы:**
- Строки **закрашены цветами** участников (градиент по долям)
- Нераспределённые — пунктирная серая рамка
- Внизу **индикатор распределения** — общая сумма по участникам

---

## 2. Шторка Claim (для одной позиции)

![Шторка claim](/Users/user/.gemini/antigravity/brain/3fe76030-230c-4058-85e4-0fab20800e9a/claim_sheet_clarified_1769913154446.png)

**Структура:**
- **Заголовок:** `Суп Солянка` — `3000 ₽`
- **Несколько рядов-сплитов** внутри (каждый — часть позиции)
- **"+ Добавить ещё"** — новый ряд для распределения
- **"Осталось: x15 (1500₽)"** — нераспределённый остаток

**Пример для Суп Солянка x30:**
- Row 1: x10 → Я и Аня поровну (по 500₽)
- Row 2: x5 → Петя 300₽ фикс, Макс и Женя остаток

## 4. Переход: Поровну → Фикс. сумма

![Переход](/Users/user/.gemini/antigravity/brain/3fe76030-230c-4058-85e4-0fab20800e9a/fixed_amount_transition_1769913219546.png)

**Механика:**
1. По умолчанию — **поровну** ("по 500₽ каждому")
2. Ссылка **"указать сумму"** под бейджем
3. Степпер для ввода суммы
4. После сохранения: бейдж показывает `Я: 300₽`, остальные `Ост.`
