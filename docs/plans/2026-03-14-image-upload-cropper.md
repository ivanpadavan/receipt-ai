# План на 2026-03-14: multi-image upload и cropper на главной

## Что мы делаем

Делаем главный экран, который умеет работать не с одной картинкой чека, а с набором изображений.

Целевое поведение:
- можно загрузить несколько изображений одного чека;
- для каждой картинки сохраняются:
  - `originalImageBase64`;
  - `croppedImageBase64`;
  - `crop`;
  - `zoom`;
  - `aspect`;
- повторное редактирование должно открываться от оригинала, но с восстановлением сохранённых параметров crop;
- на распознавание уходит массив `croppedImageBase64[]`, а не одна строка;
- на главной нужен понятный multi-image UI:
  - горизонтальный ряд изображений;
  - добавление ещё одной картинки;
  - дальнейшая настройка overlay/layout без потери уже загруженных картинок.

## Что сейчас недоделано

Главный незавершённый кусок сейчас не в data-contract, а в UI главной.

На [app/page.tsx](/Users/user/Developer/receipt-ai/app/page.tsx) мы в процессе ручной доводки multi-image области.

Что ещё не доведено:

- точная геометрия карточки/ряда после последних ручных правок;
- консистентный вид для одного изображения и для нескольких.

### 2. Upload panel ещё не доведён до финального состояния

Сейчас появился переиспользуемый `ReceiptUploadPanel`, который:
- используется как основной блок загрузки;
- используется как compact-вариант “добавить ещё”.

Но compact-вариант ещё не финализирован визуально:
- нужно довести его layout;
- нужно убедиться, что он логично стоит последним в ряду;
- нужно проверить, что он не ломает общий ритм карточки.

### 3. UI-действия над уже загруженными картинками не завершены

После последних итераций по главной странице нужно отдельно проверить и при необходимости вернуть/доделать:
- `edit`;
- `remove`;
- корректное состояние overlay при наличии картинок.

### 4. Browser coverage по главной сейчас не является финальной

Есть отдельный документ про browser test, но по факту это не финальная точка.

Причины:
- browser suite по главной заводился как вспомогательный;

- текущая задача упёрлась в ручную доводку самой страницы, а не тестов.

Итог:

- сначала надо стабилизировать сам UI на [app/page.tsx](/Users/user/Developer/receipt-ai/app/page.tsx);
